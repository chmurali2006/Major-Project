# MANIFEST — implementation package

**Project:** A Fragile Watermarking for Medical Image Tamper Detection
**Established:** 2026-10-19, built from zero.
**Purpose of this package:** everything needed to start implementation in a
new chat, and nothing else.

## Not in this package, deliberately

- **EXPECTED_RESULTS.txt** — the sealed expectations. It stays in the
  workspace untouched and is excluded from the archive on purpose: its value is
  that it was written before any result existed, and a fresh implementation
  chat must not read it. Open it only when results are frozen.
- No earlier blueprint, plan, synopsis or briefing pack. The dossier replaces
  all of them; two authorities is how contradictions start.
- No pilot output and no prior measured number. Every number this project
  reports will come from its own receipts.

## Four rules that hold across every file

1. The dossier is the only authority. A file that disagrees with it is wrong.
2. The title is fixed and never reworded.
3. The battery is twenty-two conditions. Any other count is withdrawn.
4. A number without a receipt does not exist.
