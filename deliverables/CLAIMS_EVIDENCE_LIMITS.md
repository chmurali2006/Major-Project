# Claims, evidence, limits — review handout

**Status date: 2026-10-19 UTC.** This handout summarizes evidence lines; it is not a new experiment. T1 returned and ingested a three-model classifier validation on fixed TRAIN/validation only, with `test_accessed:false`; its full metrics are in `deliverables/T1_VALIDATION_RESULTS.md`. We checked returned records and hashes but did not independently re-execute original image transformations or classifier inference locally. An earlier `isic-study-v2` run receipt reports 1,000 test items; exact membership is unavailable, so overlap with the later 500-image holdout is unknown. The later holdout is non-confirmatory development evidence and closed to additional outcome analysis. See `deliverables/TEST_SPLIT_RECOVERY_DECISION.md` and `deliverables/GATE0_PROVENANCE_STATUS.md`. Dates later than 2026-10-19 in retained run receipts/reports are future-dated relative to this status and are not validated as execution dates.

## Presentation rule

Label each number by split, method, and evidence status. Distinguish **receipt verification** from **pixel/operator replay**. Do not call validation an independent test, do not infer patient independence, and do not make clinical, novelty, SOTA, or universal-robustness claims. This handout is a summary of the cited repository receipts, not new experimental evidence.
