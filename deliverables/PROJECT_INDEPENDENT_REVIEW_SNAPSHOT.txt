1. EXECUTIVE SUMMARY AND HONEST CURRENT POSITION

The student wants both a rigorous comparative study and a differentiated implemented contribution. The project investigates three distinct questions:
A. Can exact image-content integrity be verified under declared trust assumptions?
B. How much localisation can be provided at a given evidence-storage budget, and at what latency?
C. What diagnostic-classifier effects accompany image operations or embedding modifications?

The strongest completed medical-image evidence is a 500-image, 15,000-record comparison of three detached signed-evidence methods. Compact evidence saves storage but costs verification time and loses fine localisation coverage for several global operations. A separate frozen-classifier evaluation covers 500 images and 12 operations, with 6,000 records. It shows that overall accuracy can improve while melanoma sensitivity deteriorates.

The new experimental extension is implemented: standard fixed QIM carriers plus classifier-guided correction of non-carrier pixels. It preserves tested clean carrier samples and message recovery, but has NOT demonstrated medical benefit or novelty. Synthetic controls expose increased distortion, an unseen-model deterioration counterexample, and random search matching the guided objective. The bounded medical TRAIN pilot notebook is prepared and uploaded; no pilot result has been reviewed at this snapshot. Do not describe that pilot as completed or assume it is running.

There is currently NO demonstrated novel/SOTA-superior main method, NO clinical-safety evidence, and NO independent final-test result. The dossier deliberately includes this because an independent review should evaluate the actual research gap, not a sales narrative.

2. WHY THIS PROJECT EXISTS AND WHAT WOULD BE USEFUL

Medical images transmitted or stored outside the acquisition system may change. A system may need to detect exact changes, localise them, or tolerate specified processing operations. These are different contracts. A visually harmless JPEG conversion is still a different decoded RGB image; conversely, a small malicious edit may leave a global classifier prediction unchanged.

The practical research question is whether useful localisation can be provided with less external evidence, and how that tradeoff interacts with runtime and diagnostic measurements. Digital signatures, hashing, watermarking, tile manifests and segmentation already exist; combining them is not automatically novel.

A useful outcome could be an experimentally characterised evidence/coverage/latency tradeoff and, if supported later, a constrained embedding improvement. It is also scientifically acceptable to conclude the candidate is not advantageous. Faculty appreciation cannot be guaranteed and is not an evidence criterion.

3. SYSTEM STRUCTURE: RELATED EXPERIMENTS, NOT ONE FINISHED PIPELINE

TRACK A — STRICT INTEGRITY / LOCALISATION STUDY
Input: prepared 512x512 uint8 RGB image.
Issuer: produces full4, full8 or compact bounded289 evidence and signs it.
Receiver: uses a separately trusted public key and expected image/version context, verifies evidence, and attempts localisation.
Outputs: integrity verdict, localisation map where available, abstention/coverage, packet size and timings.
Important: these detached methods do not embed or alter image pixels; their embedding MSE is zero. They must not be depicted as if they need the diagnostic-correction extension.

TRACK B — LEARNED LOCALISATION INVESTIGATION
Earlier main and attention-enhanced refiners were investigated. Current selected learned rules failed. They are not successful components of the final method. The project retains their results and synthetic failure diagnostics instead of tuning evaluation thresholds into apparent success.

TRACK C — FROZEN CLASSIFIER IMPACT STUDY
Input: original prepared images and explicitly defined operations.
Frozen DenseNet121 predicts before/after each operation.
Outputs: confusion matrices, accuracy, balanced accuracy, macro F1, melanoma sensitivity, AUC, prediction flips and paired intervals.
This measures original-image operator effects, NOT embedding-attributable effects.

TRACK D — CANDIDATE EMBEDDING EXTENSION
Input: original RGB image, binary message, frozen guiding classifier.
Standard pair-difference QIM embeds one bit per spatial block in two red-channel samples. Guided correction adjusts only non-carrier samples, within integer RGB bounds, to reduce prediction KL divergence from the original image.
Blind message decoding is separate from signed full-RGB authentication. A non-carrier edit can leave the message intact while changing content.
Outputs: recovery, distortion, guide/evaluator predictions, search/query receipts, authentication costs and failure reports.
This is implemented research code, not established robust or secure medical watermarking.

5. METHODS AND SECURITY CONTRACT

Full4: detached signed grid over 4x4 RGB tiles; 524,378 bytes/image.
Full8: detached signed grid over 8x8 RGB tiles; 131,162 bytes/image.
Compact bounded289: 18,620 bytes/image; attempts bounded change recovery from compact evidence. Fine localisation is conditional on successful decoding. Read the exact source/returned protocol for the construction; its name is not a universal capacity guarantee.

Full grid evidence uses library Ed25519 signatures and SHA256 with geometry/version/position binding. Standard primitives and signed manifests are prior art, not a new cryptographic construction. Binary full-grid packet accounting includes a 26-byte header, 32-byte tile digests and a 64-byte signature.

Authentication assumptions and exclusions:
- Public key must be independently trusted; accepting a key supplied by an attacker with a sidecar proves nothing about legitimate origin.
- Expected image/version identity and replay/freshness policy must come from an external trusted workflow.
- A valid signature establishes consistency with signed bytes under that key, not acquisition authenticity, correct patient identity or medical truth.
- Key custody, revocation, source compromise, complete metadata binding and a deployment identity system are not solved.
- This is decoded-RGB research code, not a DICOM PS3.15 signature-profile implementation or regulatory certification.
- No general proof of resistance to adaptive attacks or colluding authorised issuers is established.
- Earlier shared-secret HMAC carriers have different trust assumptions from Ed25519 sidecars and must not be ranked as equivalent systems without explanation.
- Legacy luma/brightness carrier collisions were found during development; those legacy designs are not certified by current results.

Metrics:
Pixel truth is exact changed decoded-RGB pixels, not semantic lesion removal or clinician annotations. Expanded tile maps may include unchanged pixels. Map IoU is conditional on availability unless explicitly otherwise stated. Abstention is not zero error. Global operations described as paper-benign remain integrity violations under the exact-RGB contract.

10. IMPLEMENTED EXTENSION: DIAGNOSTIC-CONSTRAINED EMBEDDING

Source: src/diagnostic_constrained_embedding.py.
Defaults: block8, QIM step8; two red carrier samples per block;4096 message bits per512 image; correction bound4 RGB levels;12 steps of1 RGB level. Standard QIM is established prior art. Carrier locations are public, so targeted message tampering is possible. This is not a robust authentication construction.

Guided objective: KL(original guide probabilities || corrected guide probabilities), using frozen classifier weights and input gradients. Candidate outputs are rounded uint8, carriers restored exactly, and a strict lower-KL selection rule includes fixed embedding as the fallback. Guide improvement is partly built into selection; it is not an independent efficacy endpoint. Original predictions can be wrong.

Six controls in TRAIN pilot v2:
1. Fixed QIM.
2. Uniform weaker QIM: changes embedding margin, not equal-robustness control.
3. Energy-matched random directions: exact per-sample distortion magnitudes, not query/compute matched; uses guided output magnitudes.
4. Guided correction.
5. Forward-query-matched random search: same original/baseline/search forward budget, same carrier locks and non-carrier Linf allowance; not energy, wall-clock or gradient-compute matched.
6. Strict distortion-gated correction: evaluates the already generated guided output and falls back to fixed if squared error increases. It does not save optimisation cost.

At12 steps, guided optimisation uses27 forward and12 backward queries; random search uses27 forward and0 backward queries, excluding separate reporting/evaluator predictions and shared data preparation. Reported counts refer to optimisation, not total program calls.

A full signed4 sidecar authenticates each final RGB image independently; its entire524378 bytes is counted. The included public key is a reproducibility aid, not a deployment trust anchor. Payload recovery and exact signed integrity are evaluated separately under operators.

STRUCTURAL LIMIT — NOT JUST AN EMPIRICAL FAILURE:
Let C be locked carriers, x original and b fixed embedding. b equals x outside C. For any y with y[C]=b[C],
||y-x||^2 = ||b-x||^2 + ||(y-x)[outside C]||^2.
Every nonzero non-carrier correction therefore strictly increases squared distortion over b. Equal-distortion improvement over this fixed baseline is impossible under these constraints. The strict gate necessarily rejects nonzero correction. A useful claim must justify a tradeoff or test a separately versioned formulation; no such replacement formulation is implemented/proven here.

Executed SYNTHETIC8x8 example: baseline MSE.166667, guideKL.048425, unseenKL.048425. Guided MSE.25, guideKL0, unseenKL.185144. Energy-matched random tied this fixture. A stronger19-forward-query random search also attained guideKL0; guided additionally used8 backward queries. The distortion gate rejected correction, squared error48 vs32. All returned clean payloads decoded. This is an explicit counterexample to automatic guide-to-unseen-model transfer and evidence against treating this toy as efficacy. A non-carrier edit leaves payload recovery unchanged but fails separate signed RGB verification.
