How to interpret this

  • Inspect each edit family, not a pooled average that hides misses. Some large patches can favour learned boundaries; small exact changes can favour fragile authentication.
  • Exact-match HMAC and signed digests are not equivalent to robust learned localisation. The learned mask is not a cryptographic verdict.
  • JPEG is reported separately. This uses EditGuard clean weights, not the degradation-trained checkpoint; do not generalise to the latter.
  • Any-pixel image positivity is a diagnostic here, not the published method's calibrated image-level decision.
  • No ISIC or clinical evaluation performed. Example alpha-channel removal is recorded separately in the provenance receipt.
  • CPU timings are descriptive, not statistically stable latency benchmarks. Signature sidecar storage and embedded pixel distortion are distinct costs.
  • No model is declared the winner. These results establish runnable baseline inference, not a new contribution.
