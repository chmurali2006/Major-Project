Trust boundary and limitations

Keys and version IDs are generated on the server, kept in memory for one hour, and never exported. Downloaded PNGs cannot be independently verified after the session ends because this workspace does not export a key-management package. Session links are bearer capabilities; do not share them. This preview is not a production medical service.

VERIFIED means the received watermarked blocks match this session's authentication tags. It does not prove the image is medically truthful. FAILED_INTEGRITY does not prove malicious intent. JPEG and other processing break this fragile watermark. Old valid content can be replayed if its original key/version remains accepted. A server error or expired session is not an integrity verdict.

No learned localisation or superiority claim. Synthetic fixtures are demonstrations only. Pixel data remains in browser/server memory; application code does not write uploads to disk.
